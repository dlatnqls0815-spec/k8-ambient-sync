# 기술 결정

## 2026-11-07 — 관측이 제어보다 먼저
순정 조명에 쓰지 않는다. HMG-API `LightRelay`의 방송 수신 경로를 조사하되
공개 vehicle API가 ambient 구독을 제공한다고 가정하지 않는다.
16비트 RGB에는 테마 코드가 포함될 수 있으므로 8비트 잘라내기/정규화를 금지한다.

## 2026-11-07 — Java 7 코어, 모의 transport
HMG-API는 Java/API19 환경이다. 코어는 Android 의존 없이 같은 언어로 검증한다.
PC의 파일 저장 유틸리티는 host에 분리한다. 실제 장치 transport는 작성하지 않는다.
공개 Lotus 후보는 이름을 붙여 구분하고, 후보 패킷 테스트가 K8 장치 검증을 의미하지 않음을 명시한다.

## 2026-11-07 — 직접 연결 우선, 장비 구매 보류
Gen5W BLE 미확인 상태에서 Galaxy 또는 ESP32를 필수로 만들지 않는다.
200ms는 실측 목표이며 모의 시계 테스트의 숫자로 달성했다고 주장하지 않는다.

## 2026-11-07 — 로컬 작업
첫 세션에서는 기존 Git 인증으로 비공개 빈 저장소를 확인했고 사용자 답변에 따라 Push하지 않았다.
main에 초기 기준을 만들고 기능은 codex 브랜치에서 진행한다.
기존 Codex/GitHub 로그인이나 전역 Git 설정은 바꾸지 않는다.

## 2026-11-07 — GitHub 동기화 재개
사용자가 GitHub 로그인 완료를 알렸다. 원래 지시서의 원격 Push 요청을 재개한다.
인증된 계정의 저장소 쓰기 권한, private 상태와 원격 브랜치 부재를 다시 확인했다.
초기 main과 기능 브랜치만 명시적으로 일반 Push한다. main에 구현을 병합하거나 강제 Push하지 않는다.
기존 179개 검사/API19 계약 컴파일 이후 실행 코드는 바뀌지 않아 같은 검사는 반복하지 않는다.

## 2026-11-07 — 라이선스와 경계
새 코드는 HMG 연동을 고려해 AGPL version 3로 통일한다(`LICENSE`, `NOTICE.md`).
외부 구현을 복사하지 않고 공개 인터페이스/패킷 사실만 독자 구현한다.
라이선스 미확인 코드·팔레트는 사용하지 않는다. 원본 소스와 빌드 의존성은 커밋하지 않는다.

## 2026-11-07 — 실제 Galaxy 자료 단계
사용자가 무선 디버깅을 요청했다. 기존 페어링의 표준 ADB mDNS 광고로 재연결한 뒤
Samsung/API/비차량 조건을 확인하고 고정 Lotus 패키지의 OS·버전 메타데이터만 읽었다.
실제 값은 Android 17/API37, LotusLamp X 5.21.03(425)다.
base APK는 로컬 private에만 복사했다. 앱 실행·설정 변경·기기 키/계정/앱 데이터 읽기는 하지 않았다.
차량·조명은 현재 접근 불가하므로 HCI 실측을 다음 정차 시험으로 남긴다.

## 2026-11-07 — HCI 분석 범위
HCI/L2CAP 재조립을 새로 구현하지 않고 TShark의 선별 필드 TSV를 읽는다.
버전·헤더·값·범위·세션을 검증하고 후보 형식의 정규화 값만 남긴다.
원본 ATT payload와 식별자·경로를 출력하지 않으며 결과 파일은 private에만 쓴다.
후보 일치만으로 프로토콜·UUID·LE/Classic·조명 반영·ACK를 확정하지 않는다.
도구가 TShark를 설치하거나 캡처·Bluetooth 송신을 자동 실행하지 않는다.

## 2026-11-07 — 설치본의 여러 프로토콜
실제 5.21.03 base APK에 E1/E2 builder와 조건부 암호화 분기가 존재함을 정적으로 확인했다.
RGB 일부의 일치로 밝기·전원·초기화까지 일치한다고 판단하지 않는다.
기존 후보 코덱은 모의 전용으로 유지하고 실제 HCI/조명 반응으로 대상 분기를 확인한 뒤 연동한다.
