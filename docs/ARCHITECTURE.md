# 구조

현재 구현 범위와 실차 미검증 경계를 함께 기록한다.

```text
순정 SML 방송 → [진단 Hook 소스: 실차 미검증] → raw 상태
                                                   ↓ 값 의미 검증 필요
가상 정규화 상태 → Java 동기화 코어 → 후보 패킷 → 모의 컨트롤러
```

RGB/밝기/전원 정규화는 raw와 분리한다. 테마 코드와 알 수 없는 값은 추정하지 않는다.
실제 BLE transport·기기 선택·페어링·CAN/LIN 송신은 이 단계에 없다.

| 안 | 경로 | 현재 판단 | 채택 조건 |
|---|---|---|---|
| A 우선 | Gen5W 관측 → Gen5W GATT → 사제 조명 | 상태 방송 근거 있음, K8/LE 미확인 | Hook·Central·GATT·대상 프로토콜·동시연결 실측 |
| B 대안 | Gen5W 관측 → Galaxy 중계 → GATT | 중계 프로토콜/백그라운드/연결 미설계 | A의 제약이 확인된 뒤 검토 |
| C 최후 | Gen5W → 별도 장치 → 조명 | 하드웨어 구매 필요성 미입증 | A/B 불가 근거가 있을 때만 |

음악/속도/색순환은 기본 동기화가 안정화된 뒤 추가한다.
차량 기본 기능과 사용자 순정 선택이 우선이다.
