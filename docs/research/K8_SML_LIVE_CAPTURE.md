# K8 순정 SML 실측 — 2026-11-07

차량을 휴대폰 핫스팟과 연결한 뒤 기존 무선 ADB로 GL3HEV.KOR.*.260902,
Android 4.4.2/API19를 확인했다. 최초 `logcat -d`에는 선별 SML 0줄이었다.
이후 읽기 전용 실시간 SystemService 로그 감시 5분에서 관련 39줄을 수집했다.
원본 로그·ADB 주소·실제 파일은 `private/vehicle-adb/`에만 둔다.

| 관측 | 결과 | 해석 범위 |
|---|---:|---|
| RGB 설정 요청 | 7줄 | 감시 시작 때 기존 버퍼도 출력되므로 처음 3개를 이번 사용자 조작으로 확정하지 않음. 마지막 1개는 복원일 가능성. |
| 밝기 설정 요청 | 6줄 | `setSMLConfiguration(mode=5)`의 data가 순서대로 1, 3, 4, 8, 7, 11. |
| 상태 응답 | 26줄 | 각 밝기 요청 직후 9바이트 응답의 7번째 바이트가 요청 data와 일치. |

사용자가 **꺼짐을 누른 뒤 1단계를 눌렀을 때 실제로 켜졌다**고 확인했다.
따라서 K8에서는 관측 밝기 1을 켜진 최소 단계로 취급한다. 기존 EV6 참조의
`raw=1 → OFF` 규칙을 K8에 적용하지 않는다. 11은 이번 조작의 최대 단계다.
OFF 직후의 원시 상태와 전원 바이트 의미는 이번 필터에서 확인되지 않았다.

RGB 상태는 big-endian 16비트 채널이며 일부 관측값이 255를 넘었다.
실제 순정 팔레트와 Lotus RGB 대응이 확인되기 전에는 하위 8비트만 사용하거나
전체 RGB를 0~255로 변환하지 않는다. 현재 1~11 단계의 밝기만 선형 임시 정규화하며,
순정 11→사제 약20%라는 사용자 육안 기준을 최대점으로 삼는다.
중간 단계의 체감 광도·실제 Lotus 명령은 휴대폰 HCI 원본 분석 후 검증한다.

ADB shell에서 `/data/hmgapi/` 일부 파일은 권한 부족으로 읽을 수 없었다.
기존 USB 사본의 보고서·맵은 이미 private에 보존돼 있으므로 새 보고서를 생성하지 않았다.
BLE feature 선언과 HMG 관련 프로세스의 순간 관측은 확인됐지만
실제 Gen5W GATT Central 연결이나 실시간 Hook 상태의 증거는 아니다.
